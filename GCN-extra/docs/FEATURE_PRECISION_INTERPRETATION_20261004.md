# GCN-extra 输入特征精度消融：17 图结论

## 实验边界

固定源代码为 `8aeef1613fdeaeb929379874c4152eccde620f74`，原 BF16 归约与 AMX 后半段保持不变；新 FP32 路径仅改变邻居特征存储、加载和解码。两层均为 128→128→128、随机 H/W、单位边权，32 个物理核、单 socket、默认 NUMA。诊断作业 `10867492` 与扩展作业 `10868182` 分别在共享节点运行；每张图的对照均在同一进程、同一节点内采用往返顺序的 10 次完整两层测量。原 TFS 和源码中的 MKL 是锚点，不作为精度完全相同的比较对象。

完整数据与原始重复值见 [实验报告](../results/feature-precision-20261004/GCN_EXTRA_FEATURE_PRECISION_ABLATION.md)、[成对比较](../results/feature-precision-20261004/paired_comparisons.csv)、[数值检查](../results/feature-precision-20261004/correctness.csv)、[PMU](../results/feature-precision-20261004/pmu_summary.csv) 和 [17 图 PDF](../results/feature-precision-20261004/feature_precision_paired_e2e.pdf)。

## 主要观察

- 17 图的 408 项数值检查、102 项逐位等价检查、136 项插桩一致性检查全部通过。BF16 和 FP32 分别有匹配自身输入数值的 reference；二者输出差异不能直接推断分类准确率。
- BF16 在 B64 和 FULL 下均赢 **16/17 图**。唯一相反的是低平均度的 RoadNet-CA：FP32 在两种粒度下均约快 **6%**。按每图成对中位数计算，`FP32/BF16` 两层时间比的跨图几何平均为 B64 **1.375**、FULL **1.414**；这是描述性汇总，不是跨节点绝对时间的直接比较。
- 五张预注册诊断图的完整两层中位数（ms）：Products B64 为 **286.84 / 453.24**、FULL 为 **285.50 / 440.73**；Reddit 为 **123.21 / 398.03**、**135.84 / 463.46**；Myciel 为 **1124.76 / 2062.02**、**2468.57 / 3722.93**；RoadNet-CA 为 **39.96 / 37.70**、**40.16 / 37.88**；wiki-Talk 为 **49.27 / 52.21**、**47.13 / 49.26**。每对按 BF16 / FP32 顺序。
- 层间全图 FP32→BF16 转换在 B64 BF16 路径的 17 图中位数为 **3.53 ms**，最大 **35.33 ms**（rgg），中位时间占比约 **4.45%**。Myciel 为 **0.88 ms**，远小于其邻居聚合时间；Email-Enron 等短路径中绝对时间虽小，占比可超过 **10%**。因此它通常不是高边数图的主瓶颈，但不能一概忽略。
- 代码确实去掉了 FP32 输入路径的逐邻居 BF16→FP32 指令；相同数值的 matched-input 单层对照仍显示 BF16 多数更快，表明“省掉解码”没有抵消 FP32 特征读取字节翻倍及其完整访存效果。插桩的 decode、load、FP32 add 子时间是采样线程诊断，不能除以端到端时间当作独立成本或因果加速预测。
- 两种粒度内均未出现稳定的 BF16/FP32 优势方向反转，故没有形成预设的精度×粒度 crossover。但交互强度不同：Myciel 的 FULL/B64 时间比，BF16 为 **2.195**、FP32 为 **1.805**；FP32 没有消除 FULL 退化。Indochina 的 FULL-FP32 **417.04 ms**，B64-FP32 **217.68 ms**，而 BF16 的 FULL/B64 约 **0.972**。此处按脚本定义的 L3 miss 事件，FULL-FP32 约 **158M**、B64-FP32 约 **44.8M**，且 load-bound 事件约 **29.1B / 10.4B**；这些独立 PMU 诊断支持访存行为变化，但不是 DRAM 字节数或唯一原因的证明。

## 研究取舍

对当前 128 维、两层、单位边权算子，BF16 适合作为默认稀疏特征表示，RoadNet-CA 是必须保留的反例。17 图中仅一张图偏好 FP32，尚不足以把输入精度自适应单独立为期刊主贡献。更值得继续验证的是访问顺序与投影粒度解耦；其结果见 [P0 窗口实验](PROJECTION_WINDOW_RESULTS_20261004.md)。若未来扩展非 128 维、真实归一化 GCN 与 checkpoint，再重新审视表示与粒度的联合选择。

此次没有训练好的完整分类模型，也没有直接测得 DRAM 带宽。最初的 FP32 首次触页不对等运行已被标记为不可用；上述结果只来自修正后的独立构建与运行。
