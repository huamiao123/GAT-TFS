# Isolated C4 AVX mask-aggregation pilot (2026-10-18)

Hypothesis: on graphs where exact consumer masks offer substantial ideal vector-addition savings, merging all source feature vectors with a common mask once and distributing the result can beat per-source fanout, given exactly the same precomputed plan. This follows the completed 17-graph structural gate; it is not a new AMX or two-layer end-to-end result. Existing shared-subaggregation prior art is acknowledged.

Fixed: original unit-weight CSR and all occurrences, 128 BF16 input features, 128 FP32 aggregate features, 16 destination rows per plan tile, Identity order, no normalization, no NUMA interleave, 16 OpenMP threads, one shared `intel` node. Four predetermined cases: amazon0601 (midrange), roadNet-CA (low opportunity), hollywood-2009 (high real graph), mycielskian19 (high constructed graph). Inputs are verified against frozen inventory SHA-256. Earlier structural scan must match exactly the source count and saved-addition count in this separately built plan.

Three independent output computations use identical input and output shapes: (1) CSR rowwise BF16-decode and FP32-add aggregation, (2) a source-mask plan that decodes each source then adds to all consumer rows, (3) the *same plan* but for masks with at least two sources and two consumers, decodes and combines source vectors first and adds their aggregate to each consumer. The latter saves `(n−1)(k−1)*128` additions. Plan construction/sorting and actual resident entry/offset bytes are reported separately. The A-vs-B contrast isolates shared aggregation after plan construction, but does not isolate source-read reduction versus the CSR rowwise baseline. This uses no AMX and is **not** a substitute for rowwise FULL Identity in the full two-layer pipeline.

Correctness gate: directed, empty, tile-boundary, overlap and duplicate fixtures before real graphs. Duplicate inputs are explicitly rejected because this pilot plan stores one mask per source and cannot represent multiplicity. All selected real graphs had zero duplicate occurrences in the independent scan, and the kernel checks again. Compare per-source fanout and shared-mask outputs to rowwise FP32 reference: relative L2 and max error normalized by max(1, reference max abs), both <=1e-2, with BF16 truncation mismatch counts recorded. This gate is probe-specific; it neither replaces nor relaxes the paper's two-layer numerical gates.

Timing includes output zeroing? **No:** each method zeroes its output before starting its timer; only sparse aggregation is timed. Warmup one and three measured repetitions for each method. Fixed order rowwise, fanout, shared; this is a shared-node *pilot*, so order/frequency interference can affect times. Formal exclusive randomized-order repeats, end-to-end AMX integration, epilogue and precision matching are required before performance claims. No graph-dependent winner is treated as a deployed selector.

Every stage saves preflight hashes, protocol/source/binary hashes, commands, environment, Slurm node/accounting, raw result JSON, stdout/stderr, any failures, and updates all three GCN-extra handoffs through `record_event.py`. Paper eligibility stays false.
