# C4 register-resident strong sparse baseline (2026-10-18)

Audit of prior isolated AVX rowwise reference found repeated output-vector reads/writes per CSR edge. Canonical FULL instead holds eight AVX-512 accumulators per destination row and prefetches the next BF16 source. This fixed-protocol experiment tests whether mask sharing still helps once the sparse baseline implements that stronger register-resident computation. Prior results remain frozen; rowwise-relative earlier ratios are treated as weak-baseline diagnostics.

The only kernel change from the completed exclusive pilot is the rowwise reference: eight `__m512` FP32 accumulators per destination row, the next source's four cache lines prefetched, one output store after all neighbors. Same BF16 decoding, unit-weight original CSR, deterministic 24-bit `[0,1)` BF16 input, D=128, Identity TR16 plan and unchanged fanout/shared kernels. Chosen six graph cohort before results: Indochina-2004 and constructed Mycielskian19 (high structural saving), Hollywood (earlier rowwise-negative yet same-plan-positive), as-Skitter (medium), Reddit (fanout-heavy), RoadNet-CA (low). Plan build and storage are measured/recorded but excluded from sparse kernel timers.

Inputs are verified by frozen SHA-256; exact plan source count/saved-add count must match stage-one scan. All sparse outputs compare to register-resident rowwise with probe-specific relative L2 and normalized max <=1e-2, BF16 truncation mismatch count, and duplicated-edge rejection.
