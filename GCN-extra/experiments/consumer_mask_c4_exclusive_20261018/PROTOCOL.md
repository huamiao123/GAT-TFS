# C4 same-plan AVX sparse-stage exclusive replication (2026-10-18)

Purpose: validate the selective signal from shared-node Jobs10996305/10996636 under a single exclusive Intel AMX-class CPU node, fixed 32 physical OpenMP threads and balanced measurement order. This remains a standalone BF16-input/FP32-output sparse aggregation experiment, **not** an end-to-end GCN or AVX–AMX result. One node maximum, `intel_expr --exclusive`, default NUMA policy; no NUMA interleave. Existing canonical source and prior snapshots remain untouched.

Methods are unchanged from v2: CSR rowwise AVX reference, per-source fanout from a frozen Identity TR16 mask plan, and shared-mask source aggregation using *the same plan*. Input is deterministic 24-bit uniform `[0,1)` FP32 truncated to BF16, D=128. Four preregistered original CSR graphs: amazon0601, roadNet-CA, hollywood-2009, mycielskian19. Validate input SHA-256, source/plan counts against 17-graph structural scan, and per-method sparse-output relative L2 and normalized max <=1e-2 before any timings. Log BF16 truncation mismatches and max absolute errors. Duplicated inputs are rejected by this isolated plan; fixtures test this as well as empty/cross-tile and rounding cases.

One warmup per method, then six paired rounds of fixed balanced orders: rowwise/fanout/shared; fanout/shared/rowwise; shared/rowwise/fanout; shared/fanout/rowwise; fanout/rowwise/shared; rowwise/shared/fanout. Each method appears equally often in every slot. Output zeroing occurs before each timer and is excluded for all methods. Report raw six arrays, medians, minimum, spread, actual CPU IDs of every OpenMP worker, node topology, memory policy and Slurm accounting. Accept a **single-socket** performance interpretation only if the recorded CPU IDs all map to one socket; otherwise label a placement failure and rerun with explicit CPU affinity under a new snapshot. Same method comparisons are within one process and one job. No cross-node speedup arithmetic.

Because the baseline is a separately implemented AVX rowwise sparse stage, even a reproducible win is a mechanism result only. A paper claim requires canonical FULL Identity + AMX two-layer comparison, exact activation/conversion/precision boundary, plan amortization and more real graphs. Record negative cases and plan memory. Preserve all raw evidence, instruction/source/binary hashes, Slurm node/job, and update the three GCN-extra handoff ledgers. Paper eligible false.
