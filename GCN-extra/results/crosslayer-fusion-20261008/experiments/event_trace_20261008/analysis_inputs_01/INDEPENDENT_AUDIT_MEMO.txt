Independent parser reconstructs every smoke event directly from original CSR and dumped degree permutation, without using C++ builder or visitor. Payload bytes are sum_record ceil(event_count/4), not ceil(total_events/4). Logical source counters distinguish decode rows, current CSR reads, next-index prefetch reads, trace headers, payload bytes and offset reads. Saving current reads E->E-S does not save PF1 next-index reads.
