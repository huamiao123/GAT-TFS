# GAT 第一阶段实验记录（2026-09-28）

## 条件

数据：ogbn-arxiv；169343 节点，2484941 条 destination-row CSR 边，128 输入维，40 类。边双向去重，含每点一个 self-loop。模型 128 → 8×32 → 8×32 → 1×40；独立 heads，transform-first，FP32。oneAPI icpx 2024.1.0，MKL SGEMM，单个 intel 共享节点，作业 10782665 在 qhcn465 上完成，16 CPU，MKL_NUM_THREADS=16。attention 路径当前单线程。block size 32。源代码和二进制 SHA256 在 runs/arxiv-10782665/artifact.sha256；环境与规则哈希在同目录。该实验为第一阶段探索性基线，不是论文级独享节点性能结论。
